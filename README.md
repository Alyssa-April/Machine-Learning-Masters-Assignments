Four of the Machine Learning assignments I carried out during my Master's. Unfortunately, the code for all my assignments cannot be retrieved :(

1. Classifying oral toxicity data besides computing the test error rate of the classification model built (logistic regression model).
2. A few Multiple Linear Regression models using forward/backward validation set approach (VSA), k-fold cross-validation (CV), Ridge regression and Least Absolute Shrinkage and Selection Operator (Lasso) regression are compared amongst one another to obtain the model with the best UPDRS score predictions. 
3. Utilise decision trees in predicting student performance.
4. Performance analysis of football players via a combination of Principal Component Analysis and K-means clustering.
